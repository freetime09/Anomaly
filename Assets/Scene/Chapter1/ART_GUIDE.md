# 1챕터 초안 아트 교체 목록

32px 기준. 기존 콜라이더와 조작 유지, SpriteRenderer만 교체 권장.

- 수풀 상자: 48x48 또는 64x64, 바닥 수평, 끌 수 있는 단단한 형태.
- 통나무 다리: 192x16, 반복 가능한 몸통과 양 끝 단면.
- 바닥 버튼: 32x16, 눌림/해제 2장.
- 레버: 32x48, 좌/우 2장.
- 돌 발판: 32x16, 64x32, 수평 윗면.
- 장식 나무: 96x160, 충돌 없는 장식.
- 임시 지형 교체 타일: 32x32, 흙 속/잔디 상단/양 끝/완만한 경사.

현재 구간: 레버 → 상자 버튼 → 버튼+레버 → 레버 변형 → 상자 2개 → 버튼+레버 복합.
6분은 목표이며 실측 전. 타일맵 아트 적용 후 지형 밀도와 퍼즐 우회 검증 필요.
