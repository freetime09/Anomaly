# 1챕터 산길 타일맵 — 최종 초안

최신 구성은 576 → 320유닛(길이÷1.8), 높이 약48유닛 하강이다. 반복 다리 12개를 없애고 연속 산비탈·전망·숲 사이에 서로 다른 퍼즐 5개를 배치했다. 깊은 틈은 두 곳만 사용한다.

| 구간 | 의도 |
|---|---|
| 상자로 바위턱 오르기 | 상자를 O로 옮겨 발판을 만들거나 세운 나뭇가지를 활용 |
| 돌멩이 무게추 발판 | 둥근 돌을 나무 버튼에 남겨 매달린 원형 돌발판을 내림 |
| 쓰러뜨리는 통나무 | ㄱ 공격으로 단 하나의 온전한 통나무를 넘어뜨려 작은 계곡을 연결 |
| 나뭇가지 순간이동 | 넓은 틈 건너 N으로 나뭇가지를 꽂고 ⋉로 이동한 뒤 S로 회수 |
| 마지막 봉인 바위 | 상자로 버튼 유지 + 레버 켜기 후 나뭇가지 공격으로 둥근 바위 파괴 |

돌 이미지는 모두 원본 가로세로 비율을 유지한다. 통나무 이미지는 활성 맵 전체에 1개만 사용한다. 나무와 작은 돌은 뒤쪽 장식으로 배치한다. 체크포인트는 기존 민트 네온 효과와 소리를 유지하며 5개다.

## Unity에서 편집

- 씬: `Assets/Scene/Chapter1/Chapter1.unity`
- Hierarchy: `Chapter1_Tilemap_11_10/Terrain_Ground_여기를_페인트`
- 퍼즐: `Puzzles_5개의_서로다른_구간` 아래 각 구간
- 배경: `BackgroundTrees_충돌없음`
- 타일: `Assets/Images/11.10/Chapter1/Tiles`
- 타일 팔레트: `Assets/Images/11.10/Chapter1/Palettes/Chapter1_11_10_Palette.prefab`
- 초안 원본 배열의 편집 샘플: `Assets/Images/11.10/Chapter1/Prefabs/초안_편집용_타일맵.prefab`
- 최종 맵 프리팹: `Assets/Images/11.10/Chapter1/Prefabs/Chapter1_EditableMap.prefab`

Grid 1칸은 32픽셀 타일 1개다. AutoGrass_Soil은 흙·잔디 가장자리를 자동 연결하고, DownSlope_45는 내리막이다. 런타임에 맵을 다시 생성하지 않으므로 씬에서 칠한 타일과 옮긴 오브젝트가 그대로 적용된다. 충돌은 TilemapCollider2D + 자동 합성 CompositeCollider2D로 편집/재생 양쪽에서 갱신된다.

시작 연출, 배경 시차, 마지막 Chapter2 전환 연결을 유지한다. 이전 지형은 비활성 상태와 Reference 백업 씬으로 보관한다. 재생 중 변경은 Unity 기본 동작에 따라 되돌아가므로 최종 편집은 플레이 종료 후 저장한다.

구성 참고: [Trine 공식 소개](https://www.frozenbyte.com/games/trine/)의 물체 활용 퍼즐과 [Planet of Lana 공식 소개](https://lanagame.com/)의 풍경을 따라 이어지는 모험 표현을 참고했다. 퍼즐과 배치는 이 게임의 제스처 조작에 맞춰 별도로 구성했다.
